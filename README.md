# Aegis · painel (protótipo)

Painel web do protótipo de acompanhamento remoto do projeto Aegis Fall AI (UFU).
Mostra os sinais vitais enviados pelo app Android (relógio → celular → Supabase) e permite pedir uma medição.

- Página: https://renagod.github.io/aegis-painel/
- Acesso só com o link que contém o código do painel (`#t=...`), que **não** fica neste repositório.
- O endereço do Supabase e a chave *publishable* no `index.html` são públicos por definição; as tabelas são fechadas
  e só funções que exigem o código respondem.

Protótipo de pesquisa — não é dispositivo médico.
